# Libron Cyrillic 0.26

Неофициальная кириллическая адаптация Libron 0.25.

## Установка

Установите все четыре файла из `fonts/ttf/`. В списке шрифтов появится семейство
**Libron Cyrillic**. Если приложение уже запущено, перезапустите его.

- Windows: выделите TTF → правой кнопкой → «Установить».
- macOS: откройте TTF через «Шрифты» и нажмите «Установить».
- Linux: скопируйте TTF в `~/.local/share/fonts/LibronCyrillic/` и выполните `fc-cache -f`.
- Kindle: скопируйте четыре TTF в папку `fonts` на устройстве, затем выберите
  шрифт в настройках книги. Наличие выбора зависит от формата книги и прошивки.
- Другие читалки и Android: импортируйте TTF через настройки приложения для чтения.

Начертания: Regular, Italic, Bold, Bold Italic. Их связь внутри семейства
проверена. Оригинальный Libron можно оставить установленным рядом.

## Что добавлено

- 100 кодовых позиций: U+0400–U+045F, Ґ/ґ и Ѣ/ѣ.
- Русский алфавит целиком, включая Ё/ё; украинские и белорусские буквы.
- Кернинг для кириллицы и смешанного текста.
- Расстановка комбинируемого ударения U+0301: за́мок, замо́к.
- Кириллическая капитель `smcp` и `c2sc`. Как в исходном Libron, это
  синтетическая капитель, а не отдельно нарисованное начертание.
- Исходная латиница, цифры, пунктуация и знак № сохранены.

Это основной блок кириллицы, а не все символы Cyrillic Extended Unicode.
Отдельные болгарские и сербские локализованные формы `locl` не разрабатывались.

## Как сделана адаптация

База: Libron, commit `46cf11c80a3b3a07c5b509b79d14c0e38feb1b35` (версия 0.25).
Буквы, совпадающие по рисунку с латинскими, используют контуры самого Libron.
Специфические кириллические формы адаптированы из Literata: изменены высота,
ширина, межбуквенные интервалы, насыщенность исходного экземпляра и наклон.
Ё/ё и Ї/ї используют соответствующие акцентированные формы Libron;
другие акцентированные буквы собраны с его знаками диакритики.

Все четыре начертания собраны отдельно. Наклон курсива измерен по реальным
штрихам, а не взят из поля ItalicAngle. Дизайн проверен по алфавиту и связному
тексту. Это рабочая адаптация; отдельного профессионального ручного прохода
по каждому узлу и тестирования на физическом E Ink экране не проводилось.

## Предпросмотр и веб

`preview.html` — локальная страница проверки с вашим текстом, выбором
начертания, размера и межстрочного интервала. Она не использует сеть.
При запрете браузера на локальные веб-шрифты сначала установите TTF или
откройте папку через локальный HTTP сервер (`python3 -m http.server 8000`).

`fonts/web/libron-cyrillic.css` подключает четыре WOFF2. Пример:

```html
<link rel="stylesheet" href="fonts/web/libron-cyrillic.css">
```

```css
body { font-family: "Libron Cyrillic", serif; }
```

`specimens/` содержит изображения алфавита и текста.

## Исходники и повторная сборка

`src/` содержит изменённые FontForge SFD. `cyrillic/base/`
содержит исходные мастера Libron, а `cyrillic/Literata-*.ttf` —
зафиксированные статические экземпляры Literata, используемые адаптацией.
Параметры преобразования находятся в `cyrillic/config.json`.

Из корня репозитория выполните:

```bash
podman run --rm -v "$PWD":/work -w /work \
  ghcr.io/nicoverbruggen/fntbld-oci:latest \
  python3 scripts/add_cyrillic.py

podman run --rm -v "$PWD":/work -w /work \
  ghcr.io/nicoverbruggen/fntbld-oci:latest \
  python3 build.py
```

Второй шаг можно выполнить отдельно, чтобы собрать уже готовые SFD.
Экспорт создаёт `out/ttf/` и `out/web/`. Для автоматической проверки через
HarfBuzz нужна его системная библиотека:

```bash
python3 scripts/validate_cyrillic.py
```

## Проверка

Все четыре TTF прошли OpenType Sanitizer. Проверены покрытие букв,
наличие контуров, отсутствие обрезания добавленных символов по вертикальным
метрикам, вес и флаги начертаний, кернинг, капитель, позиционирование ударения
через HarfBuzz и соответствие таблиц символов TTF/WOFF2.
Результаты: `fonts/validation.json`. На реальном ридере пакет ещё не тестировался.
